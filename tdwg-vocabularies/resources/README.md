# TDWG Vocabularies README
This directory contains important resources to support the development and publication of community vocabularies

## Important Resources
| Title | Description | Link |
| -- | -- | -- |
| VocPub Specification | The requirements that need to be met by data claiming to conform to the VocPub profile. | https://agldwg.github.io/vocpub-profile/specification.html |
| Guidelines for the Construction, Format, and Management of Monolingual Controlled Vocabularies | Comprehensive guidelines for creating controlled vocabularies published by NISO | https://groups.niso.org/higherlogic/ws/public/download/12591/z39-19-2005r2010.pdf |
| Best practices for development of vocabularies of values | The Vocabularies Task Group (TG4) of the Biodiversity Data Quality Interest Group is exploring the approaches and technologies TDWG might use to manage vocabularies of data terms and values. | https://www.tdwg.org/community/bdq/tg-4/ |
